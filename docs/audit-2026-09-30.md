## Domaine game et cas particuliers

Les mods n'écrivent pas tous dans leur propre domaine : une partie de leurs textes vise `game:`, et le jeu de base a lui-même des trous.

- **Jeu de base 1.22.7 : 192 clés sans français** (4 vides). Surtout des objets et blocs récents (29 `item-`, 12 `block-`, 8 `itemdesc-`), des messages de commandes (`/land`, enchères, commerce) et 5 clés `worldconfig`. Mieux vaut les signaler à la traduction officielle que les porter dans un mod.
- **Clés `game:` apportées par des mods** : smithingplusplus (14, traits et attributs de forgeron), apegrapes (6, boutures de raisin), racialequality (6, oreilles), extrafurniture (1, onglet de créatif). Elles sont déjà comptées dans les tableaux ci-dessus, sous leur mod.
- **Clés qualifiées** : une clé qui contient `:` garde son domaine, quel que soit le fichier qui la porte. Une clé sans `:` prend le domaine du dossier (`assets/<domaine>/lang/fr.json`). wcfefcompat, par exemple, place des clés `game:meal-ingredient-…` dans son propre fichier.
- **Jokers** : une clé en `*` (`block-hay-aged-*`) couvre toutes les variantes. Il faut traduire la clé à l'identique, joker compris, sinon elle ne remplace pas l'anglais.
- **Sous-dossiers de lang/** : le jeu charge tout fichier nommé `fr.json` sous `lang/`, dans n'importe quel sous-dossier. expandedfoods range ses textes de compatibilité dans `lang/compatibility/<mod>/en.json` : seuls ceux des mods installés comptent (ici primitivesurvival).

## Créer ou améliorer un mod de traduction

Un mod de traduction est un zip de contenu sans code : un `modinfo.json` et des fichiers `assets/<domaine>/lang/fr.json`. La règle qui compte le plus : **ne livrer que les clés que personne ne traduit**, car en cas de doublon la dernière traduction chargée gagne.

```json
{
  "type": "content",
  "modid": "bihantradfr",
  "name": "Traductions françaises complémentaires",
  "version": "1.0.0",
  "side": "Client",
  "authors": ["Safenein"],
  "dependencies": { "game": "1.22.0" }
}
```

### Arborescence

- `assets/wcfefcompat/lang/fr.json` traduit les clés sans `:` du domaine wcfefcompat.
- Une clé d'un autre domaine s'écrit qualifiée (`"game:item-clothes-upperbody-rawhidemantle": "…"`), dans n'importe quel fichier.
- `worldconfig-fr.json` traduit les options de création de monde, à côté de `fr.json`.
- Zipper avec des `/` : un zip fait sous Windows avec des `\` (cas de vintagestoryfr et frtraductionmods) enfreint le format zip : `unzip` le signale en erreur, et bihan doit le réempaqueter avant usage.

### Ordre de chargement

Vérifié en décompilant `TranslationService` et `ModLoader` du jeu 1.22.7 :

1. Le jeu de base est chargé en premier ; n'importe quel mod l'écrase.
2. Les mods suivent par vagues de dépendances : un mod passe après tous ceux qu'il déclare dans `dependencies`.
3. Dans une même vague, l'ordre est celui des noms de fichiers.
4. Pour chaque clé, la dernière valeur lue gagne.

Un pack qui ne dépend que de `game` passe donc après la plupart des mods et écrase leurs propres traductions. Déclarer un mod en dépendance force le pack à passer après lui, mais rend ce mod obligatoire. Ne livrer que les trous rend l'ordre sans importance.

### Règles de rédaction

- Garder les clés à l'identique, jokers `*` compris.
- Garder les paramètres `{0}`, `{1}`, les balises HTML (`<a href="handbook://…">`, `<font>`) et les `\n`.
- Reprendre le vocabulaire du jeu de base (« Cuproplomb » et non « molybdochalkos ») et ses majuscules : « Clous et bandes (Bismuth) ».
- Écrire du JSON strict en UTF-8. Le jeu tolère les commentaires et les virgules finales, mais d'autres outils non.
- Une valeur anglaise vide (4 clés du jeu de base) n'a pas besoin de traduction.

### Tester

- Lancer un serveur local avec `"ServerLanguage": "fr"` : un fichier refusé laisse `Failed to load language file` dans `server-main.log`.
- Relancer l'audit (fin du document) : les clés livrées doivent quitter la liste.
- Vérifier quelques objets dans un client en français : le serveur ne montre pas l'affichage.

### Publier

- Sur la ModDB, renseigner le modid et au moins une version de jeu. Sans eux, les outils de mise à jour ne trouvent pas le mod (cas de frtraductionmods, étiqueté 0.0.0).
- Pour les petits trous, la meilleure destination reste le mod lui-même : envoyer le `fr.json` complété à son auteur évite qu'un pack séparé décroche à la version suivante.

### Générer les fichiers à traduire

Ce script relance l'audit sur n'importe quel jeu de mods. Il écrit un `<mod>.json` par mod, qui liste par domaine les textes anglais sans français : il suffit de traduire les valeurs pour obtenir un `fr.json`. Sur bihan, le premier argument est le dossier `vintagestory-mods-1.22.7` du store, le deuxième `share/vintagestory/assets` du paquet `vintagestory-server`.

```python
#!/usr/bin/env python3
"""Liste les textes anglais sans traduction française d'un jeu de mods.

Usage: audit-fr.py <dossier des zips de mods> <assets du jeu> <dossier de sortie>
"""
import json, re, sys, zipfile
from collections import defaultdict
from pathlib import Path

ENTRY = re.compile(r'^\s*"((?:[^"\\]|\\.)+)"\s*:\s*"((?:[^"\\]|\\.)*)"', re.M)
LANG = re.compile(r"^assets/([^/]+)/lang/(?:(.*)/)?(en|fr)\.json$")

def entries(raw):
    dec = lambda s: json.loads(f'"{s}"', strict=False)
    return {dec(k): dec(v) for k, v in ENTRY.findall(raw.decode("utf-8-sig", "replace"))}

def qualify(key, domain):
    return key if ":" in key else f"{domain}:{key}"

mods_dir, game_assets, out = map(Path, sys.argv[1:4])
zips = sorted(mods_dir.glob("*.zip"))
installed = set()
for z in zips:
    info = zipfile.ZipFile(z).read("modinfo.json").decode("utf-8-sig")
    installed.add(re.search(r'"modid"\s*:\s*"([^"]+)"', info, re.I).group(1).lower())

french = {qualify(k, "game") for k in entries((game_assets / "game/lang/fr.json").read_bytes())}
english = defaultdict(dict)  # mod -> {clé qualifiée: (domaine, clé, texte)}
for z in zips:
    archive = zipfile.ZipFile(z)
    for name in archive.namelist():
        m = LANG.match(name)
        if not m:
            continue
        domain, sub, lang = m.groups()
        compat = re.match(r"compatibility/([^/]+)", sub or "")
        if compat and compat.group(1).lower() not in installed:
            continue  # textes de compatibilité d'un mod absent
        for key, text in entries(archive.read(name)).items():
            if lang == "fr":
                french.add(qualify(key, domain))
            else:
                english[z.stem][qualify(key, domain)] = (domain, key, text)

out.mkdir(parents=True, exist_ok=True)
for mod, keys in sorted(english.items()):
    todo = defaultdict(dict)
    for qkey, (domain, key, text) in keys.items():
        if qkey not in french and text.strip():
            todo[domain][key] = text
    if todo:
        missing = sum(len(v) for v in todo.values())
        print(f"{mod}: {missing}/{len(keys)} clé(s) sans français")
        (out / f"{mod}.json").write_text(json.dumps(todo, ensure_ascii=False, indent=2), encoding="utf-8")
```
